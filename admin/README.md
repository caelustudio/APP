# 作品管理台（admin）

`index.html` 是 Caelus Studio 作品管理台的页面源码，用于归档与版本管理。

## 正式入口

https://caelus-admin.app.workbuddy.host/

## 说明

云端服务按域名做精确校验，本目录下的页面通过 GitHub Pages
（`https://download.caelus.top/admin/`）打开时**无法读取或保存配置**，
页面会自动检测域名并给出提示。实际管理请使用上面的正式地址。

## 可配置项

- TreeOS / CaelusOS：下载开关、版本号、下载直链、关闭提示文案
- Caelus Studio：最新版本号、安装包地址、更新说明、是否强制更新
